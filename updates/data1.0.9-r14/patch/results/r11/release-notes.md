# Phigros Script data1.0.9-r11

继续修复 R10 核对中发现的 Ark、Re：birth 曲名歧义，并重新验证最终 APK 的难度选择与谱面读取。

## 本次修复

R10 的识别器把正式曲名和别名按同一优先级匹配。Ark 同时是“望影の方舟Six”的别名；rebirth 同时用于 Re：birth 和“重生”，导致 7 个正常难度无法唯一确定歌曲。

Phigros 现在优先匹配唯一的正式曲名，再使用原识别器校验难度。没有正式曲名精确匹配时，保留原有别名和容错匹配。两个正式曲名同时命中、名称规范化后仍重复、缺少难度或出现冲突难度时，继续返回无法唯一匹配。标题内的难度也必须与难度区域一致；不存在的难度不会退回其他难度。

原有歧义已解决：Ark 的 EZ/HD/IN/AT、Re：birth 的 EZ/HD/IN 都能以正式曲名匹配。“重生”和“望影の方舟Six”的正式曲名也分别保持正确对应。SP 仍按原规则手选。
