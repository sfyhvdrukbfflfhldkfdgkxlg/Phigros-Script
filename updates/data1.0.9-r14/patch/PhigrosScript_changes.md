# Phigros Script data1.0.9-r13

本次修订基于仓库 data1.0.9 标签。主程序包名为 `io.github.phiscript`，versionCode 为 37，与 R12 签名一致，可覆盖安装。独立手势录入器包名为 `io.github.phiscript.gesturecapture`。

## 打谱与导入

- Phigros 和 Phira 共用 Phira 的读谱、判定线投影、重试时钟及演奏流程。Phigros 本地 PEZ／ZIP、网盘与下载站缓存分别从对应谱库取谱。Phira Pro 在首页有独立启动入口，启动器、录屏识别和触控服务均按所选游戏的包名判断前台。
- 重试设置只有一个入口，可分别调整 Phigros 和 Phira／Phira Pro。Phigros 初始重试延迟为 0 毫秒，Phira 系列为 700 毫秒。用户已保存的分游戏设置优先。全局偏移和触控偏移也分别保存。无障碍输入在调度前扣除本批手势计算耗时。最终 APK 中已核对旧时间表的导入和播放调用数均为 0。
- 按噪域的生效时间拆开连续手势，经过危险区域时只抬起受影响的手指，安全后再落指。并行长按和后续音符可继续。遇到无安全落点的音符可能跳过，游戏也可能把中途抬起的长按判为断连。随机落点沿判定线法向计算，同一音符在一次演奏中沿用同一偏移。
- 小飞机分享 `feyajI8g` 随附索引中有 1052 个可用文件，5 项标为缺失。下载站完整脚本包的 1057 张谱面按各自的曲目和难度加载。识别后按谱下载，缓存可在设置中删除。

## 录屏与独立手势应用

- 从 data1.0.9 的录屏服务和编码器改到横屏 1920×1080、H.264、目标 60 帧／秒、16 Mbps。自动录屏在识别限频之前接收原始画面，复用两份画面缓冲，独立按 60 Hz 提交编码。画面未更新时复用上一帧。竖屏编码尺寸为 1080×1920，手动 Phigros 录屏入口要求游戏处于横屏。
- 手势录入器使用 Android 8.0 及以上版本。在录入器中点「开始录入」，完成单指、多指或连续多段动作后点「停止录入」，再点「导出 JSON」选择保存位置。JSON 保存相对毫秒、指针 ID、像素和归一化坐标、按下、移动、抬起及取消，供开发者修改应用手势。最近一次录入可从私有草稿恢复。

## 本次验证

- 最终主程序逐项核验 1057 张谱面、677156 个音符、17782 个噪域和 9513 次坐标投影。按曲目和难度加载无跨难度替换。1037 项带常规可见难度文本的识别用例匹配成功。
- 用户提供的《Desultory Signals》AT 样本解析得到 2026 个音符、160 个噪域，并完成手势预检。另以双指长按验证穿越噪域时单指抬起与恢复，以及另一指不中断，覆盖 Root 和无障碍输入。
- 32 条实际会话代码的主机测试覆盖识别、重试、前台切换、Root 和无障碍。用户所示暂停菜单的原图及 14 个正例变体通过识别和点击位置测试。
- 两个 APK 均通过签名和 ZIP 对齐校验。主程序的依赖与重复类检查通过。自动录屏的原始帧入口、共用投屏、60 Hz 时钟、画面更新、失焦、停止和编码失败均有静态或主机模型验证。独立录入器的多指、历史移动、抬指后再按、取消与 JSON 导出数据经过回归测试。

本次没有连接运行游戏的 Android 真机。实际命中率、全连、触控延迟和持续录屏帧率仍待设备验证。
