# Phigros Script data1.0.9-r12

适用于安装了本系列 R11 的设备。主程序包名为 `io.github.phiscript`，versionCode 从 35 升为 36，签名证书与 R11 相同。可直接覆盖安装并沿用已导入的谱库。

## 演奏

- **Phigros 延迟**。无障碍输入拆批后，在提交前扣除本批计算轨迹所用的时间。重试起点、全局偏移和触控偏移按游戏分别读取。Phigros 的重试延迟默认 0 毫秒，Phira 与 Phira Pro 共用既有的 Phira 设置，未配置时为 700 毫秒。设备上已经单独保存的 Phigros 设置优先。
- **Phira Pro 启动和前台判断**。主页增加“启动 Phira Pro”，演奏模式也可选择 Pro。启动游戏、截图服务和无障碍输入使用同一个目标包名。切换到其他游戏后停止输入。Root 导入会查找普通版和 Pro 在当前 Android 用户下的谱面目录。
- **读谱**。Phigros 本地 PEZ / ZIP 沿用 Phira 导入器，网盘 JSON、Swordalt 缓存和 APK 读出的 JSON 也经过 Phira 解析器。RPE 转换保留根节点内嵌的噪域数据。两款游戏继续使用同一套重试、视口和演奏流程。
- **噪域**。按谱面的生效时间切开可选连键。在生效期间逐个安排音符，阻止跨区连线。遇到实际会穿过噪域的轨迹，Root 和无障碍分别抬起受影响的手指，其他手指继续。没有安全落点时可跳过该触点，后续音符继续。长按重新落指有可能断连。随机偏移沿判定线法向生成，每个音符在一次演奏中使用固定偏移。
- **录屏**。自动和手动录屏均使用 AVC，目标 60 fps、16 Mbps。横屏 1920×1080，竖屏 1080×1920，宽屏等比留边。截图识别和视频编码共享一次屏幕授权，走独立 Surface。游戏画面更新较慢时，编码时间轴会复用上一帧。

## 使用

1. 覆盖安装主程序。Phigros 可在「设置与工具 → 重试校准 → Phigros」查看或微调起始延迟。全局和触控偏移在当前游戏的设备设置中调整。
2. 使用 Phira Pro 时，在主页点「启动 Phira Pro」或在演奏模式中选择 Pro，再按原流程开始打谱。
3. 需要录入修改手势的样本时，安装独立的 `GestureRecorder_1.0.0.apk`。填入名称，点「开始录入」，在画布上操作后点「停止」。可回放预览和导出 JSON。JSON 保留多指标识、相对时间、轨迹和画布尺寸，供修改应用手势使用。

## 验证

- 同一份完整脚本包经新读谱入口解析。1057 张谱面、677156 个音符、17782 个噪域与清单相符，9513 次投影抽查通过。
- 用户提供的《Desultory Signals》AT 成功解码并完成手势规划，含 2026 个音符和 160 个噪域。
- 32 条会话回归覆盖识别、重试、前台切换、Root 和无障碍。另有分游戏参数测试，以及用双指长按验证一个触点在噪域抬起并恢复、另一个持续按住的回归。
- 独立手势录入器复用仓库已发布的 1.0.0，文件 SHA-256 与同仓库 data1.0.10 的录入器相同。JSON 模型回归覆盖多指、历史采样、抬指、取消和字符转义。
- 主程序和录入器均通过 APK 验签。主程序 DEX 的原有类、方法及字段依赖通过检查。录屏尺寸、60 Hz 时间轴和截屏资源生命周期做了模型验证。

本次未连接运行游戏的 Android 真机。实际音符命中率、全连、设备触控延迟及持续录屏帧率尚待实机验证。
