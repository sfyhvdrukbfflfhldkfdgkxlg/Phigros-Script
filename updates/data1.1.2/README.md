# Phigros Script data1.1.2

Phigros 确认歌曲和难度后，会从 Google 云盘按曲下载已经处理好的时间轴、触点和噪域数据。首次下载会校验内容并适配本机坐标，再次演奏可离线读取。Google 云盘暂时不可用时会自动尝试 GitHub 镜像。新安装默认启用这个谱库。升级后可在「下载 Phigros 谱面」中选择「Google 云盘 · 识别后自动下载」。两个小飞机下载入口已隐藏。

含噪域的段落继续使用长按、拖动和红键滑动手势。规划时保留可安全通过的原手势，遇到阻挡才在判定带内调整触点。Root 和无障碍在提交前还会复查实际路径。课题模式沿用同一时间轴逐首校准。

## 升级已有谱面

1. 云端谱库适用默认手势和噪域设置，以及 16∶9 玩法区域，支持宽屏手机上的居中玩法区域。直接启动识别并确认歌曲即可。要离线游玩，请先联网准备相应歌曲和难度。
2. 遇到系统边缘裁切时，应用会复查调整后的轨迹，在受阻处抬指，安全后恢复。要按自定义手势、其他玩法比例或本机触控边界重新规划整首歌，可选择 Swordalt 谱库，在「准备 Phigros 谱面」里按本机设置准备。使用本地 Phira、Phira Pro 或 Phigros 谱面时，在「曲库 → 预计算触点 → 准备已导入谱面」更新缓存。
3. 本次更新更换了噪域手势规则。此前版本生成的本地触点需要重新准备。准备完成后，演奏直接读取时间轴和已保存的坐标。课题模式需要离线使用时，请提前准备三首歌。

原始 JSON 或谱包可保留，供更换触控设置后重新准备。

## 构建与验证

在 `updates/data1.0.9-r15` 目录运行以下命令。基线 APK 和工具布局见 [R15 构建说明](../data1.0.9-r15/DATA1.1.0.md)。

```sh
python patch/build_112.py upload/baseline-r15.apk --key testkey.pk8 --cert testkey.x509.pem
python patch/tests/run_112.py deliverables/PhigrosScript_data1.1.2.apk
```

回归测试在移走原谱 JSON 后重新打开本地、联网和 APK 来源的谱面，并检查损坏缓存、旧缓存升级和课题对齐。提供原始 PGR 谱面后，还可以用 `--replay desultory-AT.json desultory-IN.json` 检查完整无障碍派发轨迹。
