# Phigros Script · data1.0.9-r16

此测试版基于上游标签 [data1.0.9-r15](https://github.com/sfyhvdrukbfflfhldkfdgkxlg/Phigros-Script/releases/tag/data1.0.9-r15)（提交 `1bea046e7c6fde7f85c22d142a404fbff452a930`），versionCode 40。应用包名和签名与 R15 相同。

- **Phigros 课题**：首页选择「演奏模式 → Phigros · 课题连续校准（三首）」。先准备对应版本的本地谱库。在 Phigros 课题选曲画面启动打谱，看到通道就绪后开始课题。每首重新识别曲名与难度，再用多帧移动音符校准；证据不足时不发送触控。转场释放旧触点，暂停或结算结束。极短开场、隐藏判定线、复杂演出或在线取谱较慢可能使首键无法校准，优先使用本地谱库。
- **录屏**：首页「录屏 → 录屏分辨率与帧率」选择 720p30、720p60、1080p30 或 1080p60。默认 1080p60。自动和手动录屏使用同一档位，下次录屏生效。
- **红键**：Phigros 和 Phira / Phira Pro 的谱面演奏共用改进后的红键规划。独立红键在实际划动前保留按下阶段，滑动后保留触点；减少为了复用旧触点而把滑动推迟的情况。
- **噪域**：对静态和平移区域连续检查路径，覆盖两个探针间扫过的窄区域；优先找判定带内可安全续接的点。旋转和缩放仍沿用 R15 的采样与关键帧检查。无安全路径时保留抬指、恢复的处理。原谱包必须含噪域数据。

从本目录构建。需要 JDK 17+、Python 3.10+，以及原 `patch/README.md` 中的 ECJ、Android SDK 35、build-tools 35、dex2jar 2.4、Kotlin stdlib；测试另需 org.json。Windows 使用 Android build-tools 的 Windows 包。准备上游签名 R15 APK 及 R15 使用的 AOSP 测试证书，运行：

```sh
python patch/build_r16.py path/to/PhigrosScript_data1.0.9-r15.apk --key path/to/testkey.pk8 --cert path/to/testkey.x509.pem
python patch/tests/run_r16.py deliverables/PhigrosScript_data1.0.9-r16.apk
```

构建检查 R15 APK 的 SHA-256，仅替换补丁 DEX 和版本元数据，并核对 APK 对齐、签名与 DEX 引用。回归从最终 APK 读取运行代码，用主机模型覆盖输入、录屏和校准。未验证 Android 真机上的判定、课题画面识别、触控延迟或持续编码性能。
