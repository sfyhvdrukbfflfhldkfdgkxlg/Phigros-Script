# Phigros Script · data1.0.9-r17

基于上游 R15 和本地 R16 的修复版，versionCode 41，沿用 R15 的应用包名和 AOSP 测试签名。

## Phira 在线谱库

首页「Phira 在线谱库」提供三个入口：

1. 按谱面编号查询并选择导入，例如 `8825`。导入后保存到本地，并选中该谱面；在 Phira 中打开相同编号后开始打谱。
2. 按曲名搜索，选择结果导入。
3. 启用「按识别结果联网导入」，切到 Phira / Phira Pro 的歌曲画面后开始打谱。识别出的曲名和难度必须唯一匹配公开在线结果，才会下载到本地谱库，并进入原来的确认、重试、演奏流程。本地谱库为空时也可以使用。

重复曲名与难度、查询结果截断、网络失败时不猜选谱面。可改用编号导入或本地 PEZ。现有本地匹配优先；正在演奏时不因新的 OCR 噪声发起慢速联网查询。

接口与文件下载参考 [Phira 官方客户端](https://github.com/TeamFlos/phira/blob/b07773cf7771a51f6ee5131ccf5a118f38550dee/phira/src/client.rs) 与 [官方模型](https://github.com/TeamFlos/phira/blob/b07773cf7771a51f6ee5131ccf5a118f38550dee/phira/src/client/model.rs)。不读取账户凭据；仅查询和下载公开谱面。

## 本次修复

- 课题启动期间等待游戏真正进入前台。前台判断改用当前应用窗口，修复投屏授权、自家悬浮窗导致旧包名缓存滞留的问题。识别或演奏中切到其他应用仍会停止并释放触点。
- 修正原生噪域的反转组合、关键帧缓动取值与累计锚点变换。保留 R16 的连续路径检测。
- 谱包里的关联噪域文件在规范化、保存前合入，支持 `<谱面名>.blockAreaList.json` 或同目录 `blockAreaList.json`。内嵌列表优先，存在多个不明确的关联文件时报告错误。
- Next 静态矩形噪域支持 BPM 和激活区间转换；Next 动态噪域目前明确拒绝导入。原生秒制动态噪域继续使用已修正的变换与路径检查。

以前已导入且丢失噪域数据的谱面需要重新导入原始 PEZ / JSON。运行代码无法从音符位置还原已经丢失的噪域。

## 构建和验证

在含 `patch/`、`tools/` 的本目录运行；工具位置与 R16 相同：

```sh
python patch/build_r17.py path/to/PhigrosScript_data1.0.9-r15.apk --key path/to/testkey.pk8 --cert path/to/testkey.x509.pem
python patch/tests/run_r17.py deliverables/PhigrosScript_data1.0.9-r17.apk
```

构建要求 JDK 17+、Python 3.10+、ECJ 3.39、Apktool 2.11.1、Android SDK / build-tools 35、dex2jar 2.4、Kotlin stdlib 2.0.21。测试另需 org.json 20240303。`build_r17.py` 校验 R15 APK，重建有改动的原生 DEX 及补丁 DEX，核对重复类、依赖、签名和对齐。源码包不含工具、APK 或签名文件。

测试使用最终签名 APK 的代码与 Android 主机模型。未在用户设备上验证游戏判定、课题 OCR、触控延迟和长时间录屏表现。具体结果和仍受限的谱面格式见交付的验证记录。
