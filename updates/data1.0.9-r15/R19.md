# Phigros Script · data1.0.9-r19

基于 R18，versionCode 43，沿用 R15–R18 的包名及 AOSP 测试签名。

## 新回放对照

两份回放均为同指纹《Desultory Signals》AT，2026 个音符，同速度和判定模式。新回放准确率 98.84255%，旧回放 95.56022%；Miss 从 83 降到 20。已命中 Tap 和 Hold 头的联合中位误差从 −44.38ms 收敛到 −5.54ms。

新回放仍有真实残留问题：独立原生噪域参考检查发现 15 个接触生命周期经过阻挡区域（旧 29 个），主要集中在 60–97 秒。这个检查按回放时刻与记录坐标进行，不能将无事件片段当作无触点，也不能仅靠整体时间微调解释全部漏判。

## 本次修改

- 派发前按实际发送时刻检查噪域，覆盖计算耗时、时间重排和 Android Path 的实际弧长时序。
- 保留逐触点抬起与恢复；一个触点不安全时，不把其他安全长按一同结束。
- 噪域时钟保护提供标准、前后 16ms、前后 24ms 档位；默认沿用标准。保守档会拒绝更多窄时间窗口，可能增加抬指。它不代表旋转和缩放的解析连续保证。

当前中位时间偏差约 5ms，不建议继续照旧报告再统一增加 40ms。先保留这次已调整的校准，再针对同一段重录对比。

## 使用

可直接覆盖安装 R15–R18，保留谱库和设置。在主页「设置与工具 → 噪域与随机点击」开启「避开谱面噪域」，先用标准时钟保护；若区域启闭附近仍漏避，再分别比较前后 16ms / 24ms。保守档可能增加抬指，宜用同一谱面、同一校准比较。

Phira 在线谱库、已导入谱面删除、课题逐首校准和录屏档位继续保留。演奏结束的状态增加「噪域提交复核」计数与耗时，便于区分搜索和实际提交阶段的问题。新版实际改善需重录确认；上面的 98.84% 和 20 Miss 属于用户提供的新回放，不是 R19 的实测成绩。

预算在几何查询之间检查；单次查询、Android 手势回调和 Root 传输本身不能被抢占。原有无障碍通道仍最多等待「计划时长 + 1000ms」的回调。新检查没有证明已消除回放中的 607/755ms 长空档，现有回放也无法区分这些空档来自计算还是框架延迟。

## 构建

工具目录沿用 R18，在当前版本目录执行：

```sh
python patch/build_r19.py path/to/PhigrosScript_data1.0.9-r15.apk --key path/to/testkey.pk8 --cert path/to/testkey.x509.pem
python patch/tests/run_r19.py deliverables/PhigrosScript_data1.0.9-r19.apk
```

校验基线仍为官方签名 R15 APK；只重建明确修改的原生和补丁 DEX。源码包不含用户原始回放、游戏文件、构建工具或签名文件。实际改善需在用户设备更新后重录验证。
