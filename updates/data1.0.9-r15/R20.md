# Phigros Script · data1.0.9-r20

基于 R19，versionCode 44，保留 R15–R19 的包名和签名，可覆盖安装。

## 触点提前计算

本地 Phira / Phira Pro、Phigros PEZ / ZIP / JSON 在导入保存后，提前计算完整点击、长按、黄键连接和红键往返轨迹。Phigros 原谱下载、按编号或识别导入同样计算已取得的谱面。仅获取目录不批量下载其中所有文件；旧谱面、APK 内首次选中的谱面及缓存失效的谱面，在建立演奏起点之前补齐。

轨迹以物理像素存储，基础间隔 4ms，并保留连接边界和噪域断点。演奏时查表、插值，缓存命中不再调用谱面坐标函数或重新搜索避让位置。实际提交时刻、Android Path 弧长及原位停留的噪域复查继续保留。

缓存核对原谱内容指纹、屏幕视口、触控边界、连键参数、噪域时钟保护和随机偏移参数。参数变化先重算，不把另一屏幕的坐标直接套用。每谱最多 150 万采样、40MiB 编码；每个存储命名空间最多 64 份、256MiB，按最近使用清理，失效或损坏时重新计算。取消不会删除已保存的原谱；未完成的触点在下次开始前补齐。

内存轨迹的总采样数同样限制为 150 万，避免多张大谱堆叠占用。重复导入先以小索引和流式校验核对已有缓存，只计算新增或失效项，并在同一批导入中复用设备与视口参数。

随机偏移在预计算时生成并随轨迹保存。同一缓存重复使用相同轨迹；曲库「重新计算触点」可刷新，修改参数也会自动使旧轨迹失效。导入时按当前设备横屏范围准备；实际游戏视口或系统边距不一致时，会在开始前重新计算。

## 安全空隙中心

避让优先选择合法判定带内安全空隙的中点，远离边缘；先合成噪域反转与重叠，再确定安全区间。若追向中点会穿过移动噪域，而原位置的连续轨迹已验证安全，则保留原位置，避免为了居中增加抬指。这里针对沿判定线法线的安全分量，不宣称全屏二维最优。

## 曲库与界面

- 曲库并列显示 Phigros 下载、导入、删除/清理，以及 Phira 在线谱库、导入、删除。
- Phigros 删除入口可管理本地导入副本和已下载缓存；两套谱库隔离，原始 PEZ / ZIP、游戏文件会保留。
- 首页、曲库弹窗、校准、触控、语言及录屏设置统一卡片、图标、留白与颜色；增加进入、按压、展开和状态切换动画。
- 系统关闭动画或开始演奏后停止动效；页面脱离时取消动画并恢复布局。长内容可滚动，按钮保持触控尺寸。
- 自定义界面动效统一采用线性插值，弹窗默认窗口动画关闭，避免与自定义过渡叠加；谱面本身的缓动保持原曲规则。
- 新应用图标以薄荷色安全弧线、白色判定线和浅红触点构成；提供传统 PNG、自适应前景和 Android 13 单色图层，源 SVG 随源码提供。

预计算去掉了重复的连接检查，并直接合并采样网格与轨迹关键点。同一开发机的预热对比中，轨迹采样阶段 AT 约 9.20→7.52 秒、IN 约 6.26→5.91 秒；379620 项坐标、时间和生命周期差异检查一致。这是主机测量，不含下载和解析，不是手机耗时承诺。同一张谱的有效内存轨迹可直接复用，不重复解码磁盘文件。

随后增加了精确时间键的几何缓存索引，并去掉红键规划中必定无法复用触点的搜索分支。原生 AT 的 24ms 保护档规划源码探针约 629ms 完成、不可用音符为 0；28 组轨迹选择与旧逻辑一致。此值仅含规划阶段，完整 APK 的预计算及长回放耗时另见验证记录。高开销查询中的取消请求也会被及时检查。
