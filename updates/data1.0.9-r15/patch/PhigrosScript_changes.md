# Phigros Script data1.0.9-r15

R15 用一个触点接连续交替的黄拖键和红划键。过去的规划器会重新选中距离下一键较近的旧手指，把已经结束的触点向后延长数秒。现在优先续接刚完成判定的手指，预留出移动时间。每个红划键仍有实际滑动，同拍分开的判定带和未结束的长按仍按需使用多指。

噪域检查现覆盖启用、关闭以及移动、旋转和缩放关键帧的前后两侧。窄于采样间隔的噪域也参与选点与路径检查。无障碍模式在噪域活动期间提交短直线，让 Android 实际播放轨迹的时序与检查时一致。被噪域封住的触点会抬起，安全后恢复，另一侧仍安全的长按继续。

## 回放验证

- Phira 公开谱面 8825《lost umbrella(yuigot Remix)》IN Lv.13，测试窗口 47.95–51.50 秒。R13 的 Root 回放峰值为 5 指，R14 两种输入的峰值均为 3 指。R15 在 Root 和无障碍输入、随机位置开启和关闭这四种组合下均为 1 指。24 个黄键均有实际触点经过判定带，9 个红键均有带位移的划动。
- 上述原谱没有噪域数据。使用《Desultory Signals》AT 的 160 个噪域另作整曲回放，Root 和无障碍输入的落指和轨迹采样均未进入噪域。另用宽度为 0.5 毫秒的噪域验证双指长按中只有受影响的一指抬起，随后恢复。
- 对 25 张含噪域谱面中的 7,266 个黄键分别在开启、关闭随机位置时检查，均找到安全判定位置。真正需要并行触点的宽幅同拍段仍可使用六指。

主程序 versionCode 为 39，与 R13、R14 使用相同包名和签名，可覆盖安装。以上数值来自签名 APK 的主机回放，游戏内成绩和真机延迟尚待实测。
