# Phigros Script data1.1.1

导入、下载或在曲库手动准备谱面时，计算蓝键落点、黄键连接、长按和红键轨迹。缓存保存每毫秒的物理像素，以及无障碍续接需要的备用端点。Root 与无障碍演奏按时钟读取坐标，遇到已失效的路径就释放对应触点。噪域提交检查仍按实际发送时刻复核，发现风险时拒绝触点。

升级后，在首页曲库打开「预计算触点」。用「准备已导入谱面」升级旧 Phira / Phigros 导入缓存，或用「准备 Phigros 谱面」指定歌曲和难度。APK 和大型离线包提供谱面来源，按曲准备所需轨迹。联网 Phigros 也先在此下载和准备，课题模式开始前准备三首。Phira 的按识别导入会在首次下载时准备触点，然后进入确认演奏。

触点缓存绑定原谱内容、实际玩法视口、边缘范围和相关设置。变更后需再次准备。演奏入口遇到未准备或损坏的缓存会提示返回曲库。纯视觉模式读取实时游戏画面。

「重试校准」里，Phira / Phira Pro 的默认延迟是 **715 毫秒**，默认只应用用户设置的全局和触控偏移。需要叠加谱包自带的 offset 时，勾选「计入谱面自带偏移」并保存。Phigros 的默认延迟是 **1700 毫秒**。升级会保留已经保存的延迟，选择「恢复默认」并保存即可使用新值。

新增或重新导入谱面时，只校验和准备本次选中的谱面。已导入曲库仍可在「准备已导入谱面」里整库更新。触点缓存按每批 1,024 个采样点解码。对一份 180,001 个采样点的长按缓存，桌面 Java 主机上 15 次测量的中位数为完整校验 12.04 毫秒、开谱解码 14.75 毫秒，优化前分别为 43.05 和 40.41 毫秒。

窄屏和大字号下，首页谱库按钮会自动换行。切到游戏时首页暂停轮询，返回首页随即刷新。预计算页面可滚动，批量准备时显示当前谱面、完成数量和取消状态。

「语言 / Language」选择 English 后，曲库、课题、录屏、触控设置和应用错误提示使用英文。曲名、谱师名与外部服务提供的文字沿用原文。

「检查更新」只提示附有可下载 APK 的较新正式版，跳过 GitHub 草稿和标为预发行的版本。已安装 data1.1.0 的用户可以从应用内检查并升级至 data1.1.1。

构建从仓库的 `updates/data1.0.9-r15` 运行，基线与工具布局见 [data1.1.0 构建说明](../data1.0.9-r15/DATA1.1.0.md)。

```sh
python patch/build_111.py upload/baseline-r15.apk --key testkey.pk8 --cert testkey.x509.pem
python patch/tests/run_111.py deliverables/PhigrosScript_data1.1.1.apk
```

签名 APK 的回归检查覆盖默认延迟、英文切换、触点缓存、逐毫秒坐标、线性动画和正式版更新。《Desultory Signals》AT、IN 使用两张原谱在 Android 主机模型中检查无障碍路径。随机偏移关闭、时钟保护为 0 毫秒时，两次演奏累计检查超过 25 万个路径采样点，进入激活噪域 0 次。真机判定和界面显示效果待实测。
