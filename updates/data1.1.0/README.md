# Phigros Script data1.1.0

基于官方 `data1.0.9-r15` APK 及本地 R16–R20 改动整理，versionCode **11000**，沿用原签名，可覆盖安装 data 系列。

本版将触点轨迹提前到谱面导入、下载阶段计算，缓存命中后查表演奏；优化复杂红键规划和噪域几何缓存，优先选择合法安全空隙中心。Phigros 下载、本地删除与 Phira 管理同级。首页与常用弹窗重新设计，自定义过渡统一线性，并加入新应用图标。

- [使用、计算规则与限制](../data1.0.9-r15/DATA1.1.0.md)
- [完整补丁源码](../data1.0.9-r15/patch)
- [最终 APK 验证记录](TESTING.md)
- 构建入口：`patch/build_110.py`
- 验证入口：`patch/tests/run_110.py`

从仓库根目录先执行 `cd updates/data1.0.9-r15`，再按使用说明准备基线和工具并运行构建、验证入口。活动补丁目录保留原路径，以复用经过验证的 R15 原生补丁及构建工具路径；根目录的旧 Alpha Gradle 工程不包含本版。
