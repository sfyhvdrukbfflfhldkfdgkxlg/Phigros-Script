# Phigros Script data1.1.0

将谱面触点轨迹提前到导入、下载时计算，演奏时复用校验后的缓存，减少实时计算压力。沿用 data 系列签名，versionCode 11000。

- 优化复杂红键规划和噪域查询，优先选择合法安全空隙中心；保留 Root / 无障碍实际提交时的噪域复核。
- Phira / Phira Pro 支持按识别结果或编号导入在线谱面，增加谱面删除；Phigros 下载、本地删除与 Phira 管理并列显示。
- Phigros 课题模式连续演奏三首歌并逐首校准，修复前台识别；调整两种输入模式的红键手势。
- 录屏可选 720p / 1080p、30 / 60fps。重做首页和常用弹窗，自定义界面动画统一线性，加入新应用图标。
- 缓存按谱面、视口和设置校验；支持重新计算、取消、坏缓存重建及容量清理。

完整回归与最终 APK 的 IN / AT 八组合原谱主机验证通过，八组检查均零入域且全部触点释放。首次完整预计算仍可能较慢，24ms 保护档开销更高；具体耗时见验证记录。尚未完成 Android 真机界面、判定与录屏实测，不保证全连或满分。

安装使用 `PhigrosScript_data1.1.0.apk`；构建与设置说明、完整源码、图标、回放分析及 SHA-256 清单随附件提供。源码构建入口为 `patch/build_110.py`，不是根目录旧 Alpha Gradle 工程。
